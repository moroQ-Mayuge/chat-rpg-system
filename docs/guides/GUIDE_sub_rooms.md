# サブ部屋と同行の使い方

**サブ部屋**は、1つの部屋の中にある区画（カフェの「窓際の席」「カウンター」、商店街の各店舗、公園の「ベンチ」など）。
同じ部屋・同じセッションのまま、チャット画面のボタンで軽く移動できる。別の建物のような独立した場所は、従来どおり別の部屋として作る。

この資料は2部構成。

- [遊ぶ人向け：同行・デート中・サブ部屋移動のルール](#遊ぶ人向け同行デート中サブ部屋移動のルール)
- [作る人向け：サブ部屋の作り方](#作る人向けサブ部屋の作り方)

## 遊ぶ人向け：同行・デート中・サブ部屋移動のルール

### サブ部屋の移動と「誰と会話するか」

チャット画面の「場所を変える」から、同じ部屋のサブ部屋へ移動する（「元の場所」＝その部屋の入口。部屋本体）。
スマホ幅ではヘッダ全体が折りたたまれているので、先頭の「▾ ヘッダ」を開くと表示される。

**プレイヤーと同じ区画にいるキャラだけが会話に参加する**。別の区画にいるキャラは部屋にはいる（退室ではない）が、発言せず、
「別の場所にいる在籍キャラ」の欄に並ぶ。プレイヤーが戻る（または彼女たちが呼び寄せられる）と会話に戻る。

### 同行の3段階

| 状態 | 付け方 | 画面での見え方 |
|---|---|---|
| なし | 初期状態 | — |
| **同行中** | 「同行」カテゴリの「同行を頼む」（`@キャラ`を選んでから） | `@キャラ`の選択ボタンがオレンジ色になる |
| **デート中** | 「同行」カテゴリの「デートに誘う」（`@キャラ`を選んでから） | 参加キャラ欄に「♡デート中」と出る |

- どちらも**確率判定**がある（相手の信頼度・恋愛度・依存度のうち一番高い値がそのまま成功率）。デート中は恋愛度だけで判定する。
- 解除は「同行をやめさせる」（同行を外す）、「デートをやめる」（デート中→同行に格下げ）、「解散」（同行中の全員の同行とデートをまとめて解除）。
- デート中は同行を含む。つまりデート中のキャラは、部屋の移動でもついてくる。
- 「モブのランダムペルソナ」が`off`のWorldでは、モブには同行・デートのフラグが付けられない（見た目だけの通行人のままになる）。

### サブ部屋へ移ったとき、誰がついてくるか

| キャラの状態 | 移動先がサブ部屋 | 移動先が「元の場所」（入口） |
|---|---|---|
| デート中 | **必ずついてくる**（判定なし） | 必ずついてくる |
| 同行中＋`@`で選んでいる | **必ずついてくる**（判定なし。何人でも） | 必ずついてくる |
| 同行中＋`@`なし | **元の場所で待機**（同行は外れない） | 待機していた分も含めて**全員合流** |
| 同行なし＋`@`で選んでいる | 判定にかけて決まる（下記。ついて来ても同行にはならず、その移動だけ） | 判定にかけて決まる |
| 同行なし＋`@`なし | 元の場所に残る | 元の場所に残る |

**同行中のキャラをサブ部屋へ連れて行くには、毎回`@`で選ぶ必要がある**（デート中だけは不要）。`@`で選べる人数に上限は無く、選んだ同行中のキャラ全員が判定なしでついてくる。選び忘れたキャラは待機になり、待機はプレイヤーが入口へ戻ると解消する。

**同行もデートもしていないキャラを`@`で選んで移動したとき（判定）**
1. 同行中のキャラ・デート中のキャラは判定なしで先に移る。判定の対象がいる時だけ、移動宣言「（@A と〈区画名〉へ移動する）」がユーザー発言として送られ、1ターンぶん会話が生成される（対象がいなければ、会話の生成なしですぐ移動する）。
2. 生成の前に、関係値で成否が確定し、ついて行く側／断る側のキャラの台詞に反映される。
3. LLMが「強引に連れて行った」場面を描いた場合は、断った相手でも同伴が成立することがある。
4. 生成のあと、実際の位置が確定し、「同行：A。Bは元の場所に残った。」というナレーションが入る。

**会話の中で自然に場所が変わった場合**（`[SCENE_CHANGE]`にサブ部屋の名前が含まれる）は判定なし。そのターンで`@`で選ばれていた同所のキャラがそのまま一緒に移る。デート中のキャラは自動でついてくる。

**イベントによる強制移動**（`サブ部屋へ強制移動`アクション）は、同伴の判定なし。デート中のキャラだけがついて行き、他は残る。

### 部屋どうしの移動（別の部屋へ行く）

同行中・デート中のキャラは、**待機中の分も含めて全員**ついてくる。新しい部屋では、入口（既定サブ部屋。無ければ部屋本体）から始まる。同行していないキャラは置いていかれる（退室扱い）。

### 呼び出し

同じ部屋の別の区画にいるキャラを「呼ぶ」（連絡先の呼び出し、`character_join`）と、新規参加ではなく、プレイヤーのいる区画へ来る。

## 作る人向け：サブ部屋の作り方

### 1. 部屋マスタでサブ部屋を定義する

上部メニュー **「部屋」** → 部屋を選んで編集 → **「サブ部屋」** セクション →「＋ サブ部屋を追加」。

| 項目 | 内容 |
|---|---|
| サブ部屋名 | 例：窓際の席。チャットのボタン名になる |
| 既定（入口） | 部屋に入った時の開始位置。**親に1つだけ**付けられる。付けなければ部屋本体から始まる |
| 場所／雰囲気（文とタグ） | 空欄なら部屋本体のまま。**タグは親のものを置き換える**ので、基調タグ（`bar, indoors`など）も含めて書く |
| 背景画像 | 空欄なら部屋本体のまま。部屋を保存してから設定する |
| 移動コスト | 入る時の消費（0なら無し） |
| 商取引の上書き | 買い物の可否、衣装入手モード、衣装の属性キー、品揃え数、更新周期、アイテムカテゴリ。項目ごとに「部屋本体のまま」を選べる。アイテムカテゴリは**1つでも選ぶと親の候補を完全に置き換える**（0件なら親のまま） |

並べ替え・削除ができる。保存で、プレイ中のセッションの位置は消えない（IDを維持して同期する）。

### 2. 出現枠の配置先（任意）

同じ部屋マスタの**参加キャラ枠**には、サブ部屋の選択欄（配置先）がある。選ぶと、そのキャラは入室時にその区画にいる。

- 空欄の枠は、**プレイヤーの開始位置と同じ**区画に出る。
- ⚠ **既定（入口）を置かない部屋で枠を区画に配置すると、入口で誰とも会えなくなる**（そのキャラは「別の場所にいる」扱いになる）。入口を置くなら、入口と同じ区画に配置する。たとえば店員を「カウンター席（既定）」に置けば、客が個室へ移った時に店員を残して二人きりになれる。
- 区画へ連れて行く動きは、`@`同伴・同行・デート中で行う。

### 3. このWorldだけの設備（任意）

**部屋マスタの編集画面の下部にある、所属World一覧の「設定」ボタン**（部屋のWorld別設定画面。「世界観」画面の部屋一覧からも開ける）の **「サブ部屋ごとの追加設備」** で、そのサブ部屋にいる時だけ見える設備を選ぶ。部屋全体の設備（親）に**加算**される。会話の「周辺」と画像生成のタグに反映される。

⚠ 選択肢に出るのは、**部屋マスタの候補カテゴリ（設備・機材のカテゴリ）に属する設備だけ**。設備を作ったら、そのカテゴリを部屋マスタの候補に追加しておくこと（追加しないと画面に出ず、画面から保存すると消える）。

### 4. コマンド・イベントを区画に連動させる

- **行動コマンド**：行動コマンド画面の「表示条件（サブ部屋）」で、選んだ区画にいる時だけ表示できる。サブ部屋の無い部屋や、入口（部屋本体）にいる時は常に非表示になる。
- **イベント条件「現在のサブ部屋」**：部屋スコープのイベントと組み合わせて、特定の区画でだけ発火させる。
- **イベントアクション「サブ部屋へ強制移動」**：イベントでプレイヤーを区画へ移す。対象は常に現在のセッション。地の文は出ないので、必要なら「台詞・ナレーション挿入」で描写する。
- 会話の流れで区画へ移動させたい場合は、「世界観」画面の**「場面転換時にシーン画像を自動生成する」**（`scene_change_enabled`）がONであること。ONだと、LLMが区画名を含む`[SCENE_CHANGE]`を出した時にサブ部屋の移動として扱われる（区画名が一致しなければ、従来どおり場所文の書き換えと場面画像の生成になる）。この設定がOFFのWorldでは、ボタン・同伴・イベントでの移動だけが使える。

### 5. 運用のコツ

- 既存の進行中ルートがあるWorldに足す時は、**既定を置かず親の部屋を入口にする**と、既存の入室・探索・品揃えのデータに影響しない。
- 区画ごとに買えるものを変える（商店街の各店舗など）には、サブ部屋ごとに「買い物: できる」と**アイテムカテゴリ**を設定する。通貨が有効なWorldで使える。
- コンテンツバンドル（zip）のエクスポート・インポートは、サブ部屋の定義・商取引・設備・枠の配置先・ルートの現在位置まで含める。
