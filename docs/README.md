# ドキュメント一覧

ルート直下は [README.md](../README.md)（セットアップ）・[CLAUDE.md](../CLAUDE.md)（Claude Code向け運用ルール）・[CHANGELOG.md](../CHANGELOG.md)（変更履歴）のみ。それ以外の開発資料はこの`docs/`配下に分類してある。

- [ROADMAP.md](ROADMAP.md) — 実装状況サマリー・リリース済み機能一覧・今後のロードマップ（v0.2.x〜v0.4.xの計画含む）
- [SPEC.md](SPEC.md) — 元々の仕様書（最新の実装を必ずしも反映していない点に注意）
- `plans/` — 個別機能の検討メモ・設計方針（実装順の記録込み）
- `investigations/` — 不具合報告・要望のバッチ調査ログ
- `guides/` — 特定機能の使い方ガイド
- `backlog/` — 積み残し課題の一覧
- `feedback/` — プレイテストセッションのフィードバック記録
